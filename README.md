# Smart-Storage-Cabinet
Đồ án xây dựng một hệ thống tủ lưu trữ thông minh có khả năng đăng ký người dùng, xác thực và mở tủ tự động bằng nhận diện khuôn mặt kết hợp cảm biến vân tay. Phần mềm sử dụng Python, giao diện Tkinter, OpenCV/YuNet/dlib-face_recognition cho xử lý khuôn mặt, SVM cho phân loại trạng thái khuôn mặt
Hãy xóa file dataset có trong dự án. Thay vào đó tạo một folder có tên dataset ngay dưới folder _pycache_.
